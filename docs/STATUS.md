## מה נבנה
- `index.html` + `styles.css`: דף נחיתה חד-עמודי בעברית (RTL), רספונסיבי: hero, אודות, מה לומדים, איך זה עובד, למה איתי, שאלות נפוצות, טופס יצירת קשר, פוטר וכפתור וואטסאפ צף.
- טופס Netlify (`name="contact"`, honeypot) עם שליחה ל-`thanks.html`.
- `netlify.toml` (publish = ".").
- עיצוב ברירת מחדל: כחול עמוק, קלף וזהב. ללא תמונות; עיטור SVG פנימי.

1. קבלת המידע לעיל והחלפת ה-placeholders.
2. חיבור מאגר GitHub ל-Netlify (Import from Git, publish directory = `.`).
3. אימות שליחת טופס באתר המפורסם (Netlify Forms, בדיקת שליחה אמיתית והופעה בלשונית Forms), ובדיקת `thanks.html`.
