## פרסונה 1 · "מיכל, ההורה המתכננת"

**מי:** אמא או אבא לבן 11–12 במודיעין והסביבה. מתחילים לחפש חצי שנה עד שנה לפני התאריך.

| | |
|---|---|
| **המשימה (Job)** | "למצוא מורה אחד שאפשר לסמוך עליו, ולסגור את זה מוקדם" |
| **טריגר** | תאריך הבר מצווה נקבע, או שחברים מהכיתה כבר התחילו ללמוד |
| **שאלות בראש** | מתי מתחילים? מה הפרשה? איזה מסלול? כמה זה עולה? |
| **איך מחפשת** | גוגל ("מורה לבר מצווה", "הכנה לבר מצווה מודיעין", "פרשת בר מצווה לפי תאריך לידה"), קבוצות הורים בפייסבוק, המלצה מחבר |
| **כאבים** | תוצאות החיפוש מלאות באינדקסים ובמודעות, בלי מורה עם פנים. לא ברור מה כלול. פוחדת להתחיל מאוחר מדי |
| **מה משכנע** | לוח זמנים ברור (חצי שנה / שלושה חודשים), מעל 20 שנות ניסיון, המלצות של הורים, תשובה מהירה בוואטסאפ |
| **ציטוט אמיתי** | "מושיק אתה באמת מורה נדיר" (הורה, הודעת וואטסאפ) |
| **ערוץ ראשי** | אתר (דף הבית + מחשבון הפרשה) → וואטסאפ |

## פרסונה 2 · "אורי, משפחה שרוצה בר מצווה בדרך שלה"

**מי:** משפחה חילונית, מסורתית-לייט או מקהילה שוויונית. רוצים שהבן יקרא בתורה, בלי להרגיש זרים.

| | |
|---|---|
| **המשימה (Job)** | "שהבן יעמוד שם בביטחון, ושאף אחד לא ינסה לשנות את הבית שלנו" |
| **טריגר** | הילד ביקש, או שסבא וסבתא מצפים לקריאה בתורה |
| **שאלות בראש** | זה מתאים גם לנו? הוא ביישן, הוא יעמוד בזה? המורה יגיע לאירוע? |
| **איך מחפשת** | גוגל ("בר מצווה חילונית", "מורה לבר מצווה"), המלצה מפה לאוזן, זום אם גרים רחוק |
| **כאבים** | חשש מהטפה. ילד לחוץ מול קהל. מורים שמתאימים בעיקר לבית דתי |
| **מה משכנע** | "מלמד גם משפחות חילוניות", "בקצב של הילד", המלצה מקהילה דומה |
| **ציטוט אמיתי** | מושיק להורה: "פעם ראשונה שאני מתפלל בשיוויוני, אני בדרך! יפה ההכלה והשיתוף ביניכם" |
| **ערוץ ראשי** | המלצה → דף הבית (סקשן הגישה + המלצות) → וואטסאפ |

**תת-פלח של שתי הפרסונות – "בלחץ זמן או רחוק":** נשארו כשלושה חודשים, או גרים רחוק ממודיעין. מה שעובד: מסלול מפטיר + הפטרה, ועמוד /online/.

## הצעת ערך

**משפט אחד:**
> מורה פרטי אחד, עם מעל 20 שנות ניסיון, שמכין את הבן שלכם לקריאה בתורה, להפטרה ולהנחת תפילין, בקצב שלו ובדרך שמכבדת את הבית שלכם, במודיעין או בזום מכל מקום.

| מה ההורה צריך | איך מושיק עונה |
|---|---|
| לדעת מתי להתחיל | שני מסלולים עם לוח זמנים: חצי שנה / שלושה חודשים |
| לדעת מה הפרשה | מחשבון פרשה לפי תאריך לידה, כולל שבתות מיוחדות |
| שהילד לא ילחץ | "בקצב של הילד", שיעור אחד בשבוע |
| שהבית שלו יכובד | מלמד גם משפחות חילוניות; נוסח אשכנזי |
| לסמוך על מישהו | פנים, שם, ניסיון, המלצות אמיתיות |
| לא לנסוע | זום מכל מקום |

**לא בהצעה (בכוונה):** מחיר באתר (הוסר לבקשת הלקוח), שיעור ניסיון (לא אושר), נוסחים אחרים.

## תסריט ראיון הורים (20 דקות, 3–5 הורים)

1. ספרו על הרגע שהבנתם שצריך להתחיל להתכונן לבר מצווה.
2. איך חיפשתם מורה? מה הקלדתם, את מי שאלתם?
3. מה גרם לכם לפסול מורה אחר?
4. מה היה החשש הכי גדול שלכם? ושל הבן?
5. למה בחרתם במושיק? מה היה הרגע שהחלטתם?
6. אם הייתם ממליצים עליו לחבר, מה הייתם אומרים במשפט אחד?

אחרי הראיונות: לעדכן את שורות "כאבים" ו"מה משכנע", ולהחליף ציטוטים בציטוטים מהראיונות (באישור).
